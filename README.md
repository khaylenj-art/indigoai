# Indigo AI — Modern Website & Autonomous Virtual Agents

A modern, high-converting agency website built with React, Vite, and Tailwind CSS. Features an Apple-inspired soft blue aesthetic, zero emojis, and interactive demonstrations of 24/7 Virtual Agents for healthcare and business lead capture.

## 🚀 Features

- **Apple Design System**: Pure white and soft sky blue color palette with SF Pro / Inter typography.
- **24/7 Autonomous Virtual Agent**: Demonstrates interactive appointment booking, day/time slot selection, and email verification dispatch.
- **Interactive Revenue Loss Calculator**: Real-time interactive slider calculating potential lost revenue from slow replies vs recovered monthly sales.
- **Trained Knowledge Base Integration**: Highlights how Virtual Agents ingest website URLs, PDFs, and FAQs to answer business questions accurately.
- **Single Flat-Fee Offer (€550 setup + €149/mo)**: Simple, high-converting pricing breakdown.
- **Name & Website URL Lead Capture**: Enquiry form modals for prospective clients.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & Vanilla CSS
- **Icons**: Lucide React
- **Animations**: Canvas Confetti & Framer Motion

## 📦 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v16+) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/indigoai-website.git
   cd indigoai-website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
